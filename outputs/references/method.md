# 方法与取舍（pdf-struct/2）

本文说明 `scripts/pdf_struct.py` 到底怎么判版面、为什么这么判、以及哪些地方刻意"不猜"。
所有阈值都在源码里以常量出现，改阈值前请先读对应小节的失败模式。

## 0. 总体流水线

```
PDF ──► 行(span 级字体信息) ──► 分栏投影 ──► 栏内段落分组 ──► 块分类
     ──► 表格网格 / 图区(位图+矢量簇) ──► 阅读顺序(带区排序) ──► 章节树
     ──► 元数据/参考文献 ──► 自检 ──► doc.json / text.md / tables / figures / overlay
```

设计原则按优先级排序：

1. **不丢字**：宁可把一行归错类（`figure_label`/`margin_artifact`），也不让一行凭空消失；
   每个被排除的块都留 `masked_chars`，统计里能对账。
2. **不拼接**：任何块不得跨越栏间空白（`selfcheck` 强制）。
3. **可回页**：每个块必须有 `page` 与 `bbox`；没有矢量坐标的（视觉转录块）显式写 `bbox: null`。
4. **可验证**：`char_recall` + overlay 图让"提得全/排得对"变成可量化的检查，而不是口头保证。

## 1. 行重建（`page_lines`）

用 `page.get_text("dict")` 取 span，每个 span 记录字号、字体名、(bold, italic, mono)、
是否上下标（flags bit0/bit1/bit4）、横向重叠比例，再把同一基线的 span 合成"行"。

同一行被拆成多个块的典型来源是编号与标题分离（`3.1` + `Attention`），
`merge_rows()` 以 `max_gap=14pt` 把"行内碎片"重新合成一行——这是"拆得清"的前提：
先有正确的行，才可能有正确的标题与段落。

## 2. 分栏（`detect_columns`）

- 只用**短行**（宽度 < 0.62 × 正文宽度）投票：通栏标题/通栏图注会把整行覆盖，不能参与投票，
  否则双栏论文永远投不出栏间空白。
- 对 x 方向做覆盖直方图，`cov[x] <= 1` 的区域算"空白"：容忍**一根**越界的行（典型是公式编号 `(2)`
  压在栏间，它会把 12pt 的 gutter 切成 7pt + 6pt 两段，两段都不达阈值——这是 v1 在 CVPR 双栏上
  判成单栏的真正原因）。
- 空白段需 ≥ 6pt 且两侧各有 ≥ max(3, 0.15×投票数) 行支撑，才认定为 gutter。
- 文档级取各页栏数的众数；若某页仍判成 1 栏但行数 > 25 且全篇是 2 栏，则继承文档级 gutter
  （`cols_derived="document_template"`），并在 `pages[].cols_derived` 里如实标注是继承来的。

失败模式：三栏以上、或整页都是通栏短行（如纯文字信件）时会退化为 1 栏，需 overlay 复核。

## 3. 段落分组（`group_lines`）

栏内按 y 排序后逐行判断是否续段：

- 上一行"没顶到右边界"（`pv[2] < right_edge - max(6, 1.15×行高)`）→ 段末；
- 或当前行有首行缩进（`cv[0] > left_edge + max(4, 0.9×行高)`）→ 新段；
- 续段还需：行距 ≤ 1.6×行高、水平重叠 ≥ 30% 行宽、字号/粗体/等宽字体一致；
- 任一行像标题（`looks_like_heading_line`）就断开——否则会出现
  `2. Related Work Residual Representations. In image recognition, VLAD…` 这种标题吞正文。

## 4. 块分类（`classify`）

判定顺序（先命中先返回）：空 → 等宽字体 `code` → arXiv 水印 / 版权许可 `margin_artifact` →
参考文献标题 `heading` → 公式（`math_density ≥ 0.12 且 数学字符 ≥ 2 且 ≤ 4 行 且无 CJK`）→
图注（`Figure/Fig./图 + 编号`，且 < 400 字符）→ 短句以句号结尾则归 `body` →
大字号粗体 `title` → 小字号（≤ 0.82×正文字号）`footnote` → 编号标题 → 其余 `body`。

两处经验：

- **"句号规则"**：`len < 40 且以句号结尾` 一律不算标题。出版商许可声明常用大字号排版，
  不加这条就会把 `scholarly works.` 当成一级标题，进而把章节树带偏。
- **上下标单独成块**（如 `i`、`n`）时，`sup_sub` 保留在块上，但不并入相邻正文，
  以免把 `x_i` 拼成 `xi`。
- **全大写编号小节**：ICLR/NeurIPS 的 camera-ready 常用"正文号字号 + 全大写 + 不加粗"排小节标题
  （`3.1 VISION TRANSFORMER (VIT)`、`4.2 COMPARISON TO STATE OF THE ART`）。只靠字号或字重会漏判，
  因此补一条判据：**编号 + rest 全大写（无小写字母）+ 单行/两行内 + 长度 ≤ 70 + 无年份/无逗号分号**。
  加逗号与年份的排除条件是必要的——参考文献条目 `12. A. Vaswani, ... 2017` 也满足"编号 + 全大写"。
  这条规则在留出样本 ViT 上补回了 7 个丢失的小节（3.1/3.2/4.1–4.6），且未改动其余四篇的任何块。

## 4.5 跨行标题的回并（`merge_title_continuations` / `merge_heading_continuations`）

段落分组刻意"标题永远单独成段"，于是**跨行标题**会被切成多块：ViT 的
`AN IMAGE IS WORTH 16X16 WORDS:` / `TRANSFORMERS FOR IMAGE RECOGNITION AT SCALE` 会变成
"标题 + 一个假的一级章节"。两个后处理负责把它合回去：

- **文档标题**：首页字号最大块 + 同字号、间距 ≤ 1.9×字号、无逗号/分号（作者行必带逗号）、
  不以句号结尾的后续块 → 并成一块（`bbox` 取并集、`n_lines` 相加），并重排该页 `id`/`order` 保持连续。
- **多行小标题**：一个标题**不可能以连接词结尾**（for/of/the/and/with/in/on/to/a/an…）。
  命中即说明它是被切断的半句（BERT 附录的三行横幅 `Appendix for “BERT: Pre-training of` /
  `Deep Bidirectional Transformers for` / `Language Understanding”`），
  把下一块并回当前标题，最多两级。

两处都写入 `warnings`（`title_merged` / `heading_merged`），不做静默修改。
实测影响：BERT 691→687 块、30→27 章节（3 个假章节消失），其余三篇的块数与章节数**完全不变**。

## 5. 表格（`find_tables` + 单元格重建）

1. 用 PyMuPDF `page.find_tables()` 拿网格（行列划分 + 单元格 bbox）。
2. **合理性闸门**：`n_rows ≥ 2 且 n_cols ≥ 2 且填充率 ≥ 0.40 且去空白文本长度 ≥ 8`，
   否则标记 `tables_rejected`，该区域**退回正文文本**（宁可是文字，也不出一个假表）。
3. **单元格文本从词框重建**：`Table.extract()` 对多行/多重文本的单元格会把 span 交错拼接
   （实测把 `3×3, 64` 拼成 `3 3××3 6 64`）。改为取 `page.get_text("words")`，
   按"词心落在 cell bbox 内"筛选，先按视觉行（y 差 ≤ 2.2pt）分组、组内按 x 排序，
   行内空格连接、行间换行——于是嵌套单元格得到 `1×1, 64 / 3×3, 64 ×3 / 1×1, 256` 这样的多行文本。
4. **不漏字**：表格区域内不属于网格的文字（`_char_overlap < 0.85`）收进 `unassigned_lines`，
   既计入该表文本，也在 `n_unassigned` 里如实计数。

## 6. 图区（`artwork_near`）

图注必须"贴着图"才算图注：

- 候选图区 = 位图 bbox ∪ 矢量绘图 rect（宽高 ≥ 1pt），按 6pt 容差聚簇，
  丢掉宽 < 24 或高 < 18 的簇（表格框线、分隔线）；
- 图注块与图区的竖直间隙 ≤ 30pt，且水平重叠 ≥ 0.25 × min(图注宽, 图区宽)；
- 图文接触后才把该块标 `caption` 并生成 `figure` 块（`bbox` = 图注 ∪ 图区）；
- 找不到图区的 `Fig. 4. First, the situation is reversed…` 这类正文句，**不会被当成图注**。

图内的文字（坐标轴刻度、图例、`3×3 conv, 64` 这类结构标注）判定为 `figure_label` 并不进正文：
判据是"块心落在任一位图/矢量矩形内" 且（字号 ≤ 0.85×正文 或 文本 ≤ 14 字符）。
它们仍保留在 `blocks` 里可核对——这是"提得全"与"正文干净"的折中。

## 7. 阅读顺序（`order_blocks`）

- 跨栏块（标题、通栏图表）作为**带区分界**：以它们的 `y0` 切分页面为若干水平带；
- 带内按栏从左到右，栏内按 y 从上到下。于是双栏页面得到"左栏到底 → 右栏顶部"的正确顺序，
  而不是按 y 逐行交错（后者是大多数简单实现的通病，会把左右栏的同高度行拼成一句话）。

`selfcheck` 会验证：没有任何块的 bbox 跨越 gutter。

## 8. 章节树、元数据、参考文献

- 章节：`heading` 依次入栈，`level` 由编号深度（`3.1.2` → 3）与字号层级共同决定，
  输出 `sections[]` 的 `id/title/level/page/bbox/block_id/path`——父子关系由 `level` 与
  用 ` / ` 连接的 `path` 表达（如 `3. Deep Residual Learning / 3.1. Residual Learning`），
  不另存 `parent`/`children`，避免两处状态不一致；`Abstract`、`References`、`Appendix A`、
  `附录`、`致谢` 固定为一级。同一 `level` 的 `path` 相等即视为兄弟节点。
  标题块的 `level` 同时写回 `blocks[].level`，`text.md` 据此渲染 `##`/`###`/`####`。
- 元数据：标题取首页字号最大的块（排除图内文字、arXiv 水印）；作者取标题与摘要之间、
  符合"人名形态"的片段（Unicode 大写开头，2–4 段），并把含机构关键词/邮箱的块划为
  `affiliation`；邮箱单独归 `emails`；摘要从 `Abstract` 起连续收取同字号块，遇到脚注标记、
  许可声明或标题即停（防止摘要吞掉引言）。
- 参考文献：从 `References/参考文献` 标题起，按 `[12]` / `[A3]` / `12.` 起始切分条目，
  跨块累积，每条带 `page` + `bbox`。

## 9. 自检（`selfcheck`）

| 不变式 | 违反后果 |
|---|---|
| 每块都有 `page` 与 `bbox`（视觉块除外，显式 null） | 退出码 4 |
| 每页 `page_order` 连续无洞 | 退出码 4 |
| 没有块跨越 gutter | 退出码 4 |
| `char_recall = 输出字符 / (文本层字符 − 页眉页脚 − 图内文字)` ≥ 0.90 | 退出码 4 |

`char_recall > 1.05` 说明同一段文字被两块输出（重复），这也是错误，需查 overlay。

## 11. 已知失败模式（如实记录）

1. 三栏以上或栏间存在整页通栏插图时，可能只判到 2 栏 → 用 overlay 复核并标 `uncertain`。
2. 表格没有框线（纯空白对齐）时 `find_tables()` 可能无输出 → 该区成为正文文本，不虚构成表。
3. 数学公式密集的段落可能被误判为 `formula`（判定只看字符密度与行数）→ 文本不丢，只是类型标签需要人工复核。
4. 扫描件没有矢量 bbox：视觉转录块只能定位到页，不能定位到框（`bbox: null`）。
5. 旋转文字（侧边水印）统一进 `margin_artifact`，不参与阅读顺序。
6. 混合栏数文档（正文单栏、附录双栏）的 `document.column_template` 只代表多数页；
   跨栏不变式按页生效，汇总时必须看 `pages[].columns`。
7. 无编号、无字号差异、与正文同字重的"暗标题"仍可能留在正文里（章节树会少一节，文字不丢）。
